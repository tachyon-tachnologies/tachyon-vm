# Code of Conduct

## Our commitment
Tachyon is an open source project, and we welcome contributions from people with different skills, backgrounds, and tools. We value thoughtful, maintainable patches, and we expect contributors to understand and take responsibility for the code they submit.

## Expected behavior
- Be respectful, and give constructive criticism.
- Explain your changes clearly in issues and pull requests.
- Match the repository's existing code style, patterns, and design intent.
- Review your own work before submission.

## Contribution guidelines
- Contributions are welcome, but they should be authored by people who understand the change.
- AI-assisted work is acceptable when it helps improve correctness, style, or clarity.
- Fully AI-generated contributions without any understanding are discouraged.
- If you use AI tools, disclose that in your contributions and verify the behaviour of the code yourself.

## What we do not want
- Vibe-coding: submitting code without understanding it inside and out.
- Blindly accepting patches from authors who cannot explain how the change works.
- Total reliance on AI for writing code (basically 100% vibe-coding).

## Enforcement
If some code in a contribution looks unsafe, or poorly written, repo maintainers may ask for revisions, or completely reject the change. This project reserves the right to decline contributions that do not meet quality expectations.

## Reporting problems
If you encounter conduct issues or have concerns about a contribution, contact the maintainers through the repo issue tracker or the preferred project communication channel.
